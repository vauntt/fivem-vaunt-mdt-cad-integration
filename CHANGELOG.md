# Changelog

Toutes les modifications notables de cette ressource sont documentées ici.

## [1.1.1] - 2026-08-26

### Ajouté

- validation automatique GitHub Actions du manifeste, du client Lua et du JavaScript NUI ;
- aperçu visuel de VAUNTCORP MDT dans le README.

### Modifié

- remplacement de `GetPlayerPed(-1)` par `PlayerPedId()` pour suivre les pratiques FiveM actuelles.

## [1.1.0] - 2026-08-26

### Ajouté

- documentation d'installation, de compatibilité et de dépannage ;
- nettoyage de la tablette à l'arrêt de la ressource ;
- fichiers de contribution, sécurité et modèles d'issues GitHub.

### Modifié

- callback NUI basé sur le nom réel de la ressource ;
- interface NUI en JavaScript natif, sans dépendance jQuery distante ;
- métadonnées FiveM et liens officiels VAUNTCORP.

## [1.0.0]

- première version publique de la tablette NUI VAUNTCORP MDT/CAD.
