# Politique de sécurité

## Versions prises en charge

La dernière version publiée de la ressource est la seule maintenue.

## Signaler une vulnérabilité

N'ouvrez pas d'issue publique pour une vulnérabilité exploitable. Utilisez le formulaire privé [GitHub Security Advisory](https://github.com/vauntt/fivem-vaunt-mdt-cad-integration/security/advisories/new) et décrivez :

- la version concernée ;
- les étapes de reproduction ;
- l'impact observé ;
- toute correction suggérée.

Ne joignez aucune donnée personnelle, clé d'API, cookie de session ou information provenant d'un serveur GTA RP réel.
